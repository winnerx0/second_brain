// Capabilities

Everything in one agent.

Six tools. One assistant. Zero context-switching.

⬡
GitHub Intelligence

Monitors all open PRs authored by you, issues assigned to you, and every push from the last 24 hours — including commit messages.

get_open_prs · get_recent_pushes
◈
Calendar Management

Create, edit, and delete Google Calendar events via natural language. All-day events, attendees, and UTC scheduling handled precisely.

create · edit · delete · list
◉
Telegram Delivery

Briefings and responses flow directly to your Telegram. Markdown formatting with graceful plain-text fallback on parse errors.

sendMessage · fallback
⬡
Persistent Memory

Store and recall facts, preferences, and patterns across sessions. Memory is backed by Postgres — no context window limits.

store_memory · recall_memories
◈
Daily Briefings

A cron-triggered morning briefing gathers all data, synthesises it through the planning agent, and pushes a concise summary each day.

cron · 0 0 * * *
◉
Chat Interface

Ask anything ad-hoc. The agent decides which tools to call, chains them as needed, and responds in Yuki's composed, precise tone.

POST /chat
// Architecture

Three commands. That's it.

No dashboards. No configuration UI. Just a server and a bot.

01
Configure

Copy the example env and fill in your API keys. GitHub token, Google service account JSON, Telegram bot — all in one file.

cp .env.example .env
# fill in keys, then:
bun run db:migrate
02
Start

Bun starts the Hono server. The cron fires at midnight, the chat endpoint is live, and Yuki is listening.

bun run dev
# server: localhost:3000
# cron: 00:00 daily
03
Chat

Send messages through your Telegram bot. Yuki fetches live data, reasons across tools, and replies with precision.

curl -X POST /chat \
-d '{"message":
{"text":"briefing"}}'
// Quick Start

Up in under a minute.

Bun, Postgres, and a few API keys are all you need.

install & run 
bun install
bun run db:migrate
bun run dev
# → http://localhost:3000
.env variables 
OPENAI_API_KEY=sk-...
GITHUB_TOKEN=ghp_...
GITHUB_USERNAME=you
GOOGLE_CALENDAR_ID=primary
GOOGLE_CREDENTIALS={...}
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
DATABASE_URL=postgres://...
Note: GOOGLE_CREDENTIALS accepts the service account JSON directly as a string. No file path, no base64 — just paste the raw JSON value.
